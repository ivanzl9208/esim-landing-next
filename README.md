# eSIM — новая версия

Публикация рабочей версии лендинга в GitHub Pages.

Исходники: [ivanzl9208/esim-landing, ветка codex/improvements](https://github.com/ivanzl9208/esim-landing/tree/codex/improvements).

Сайт собирается из исходного репозитория. Для обновления запустите workflow **Publish current landing**; параметр `source_ref` позволяет выбрать ветку или коммит.

Эталон из `main` остаётся в [исходной публикации GitHub Pages](https://ivanzl9208.github.io/esim-landing/).
